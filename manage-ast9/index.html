📖 Publishing guide

How to publish (the full workflow)

  1. Edit here — add or edit novels in this admin panel. Everything is saved in this browser.
  2. Export — click 📤 Export all (or per-novel Export). You get the JSON files + cover images.
  3. Place files — copy the JSON files into data/novels/ and covers into img/covers/ of your local site copy.
  4. Push to GitHub — commit & push. Vercel redeploys automatically. Your novels are live. 🎉

Google Drive novels

  1. Upload the novel text file to Google Drive, share as “Anyone with the link”.
  2. Paste the share link in the novel's External source field — the file ID is extracted automatically.
  3. Get a free Drive API key (Google Cloud Console → enable Drive API → create API key) and put it in js/reader.js as DRIVE_API_KEY.
  4. The reader fetches the text through Google's API and renders it inside your site — visitors never see Drive.

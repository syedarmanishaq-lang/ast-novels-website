📖 Publishing guide

How to publish (live database)

  1. Add novel — fill in title, author, description, and upload a cover image.
  2. Add content — either paste chapters below (bulk import supported), upload a PDF of the book, or link a Google Drive file.
  3. Save — choose Published and hit 💾 Save novel. It appears on the website instantly. 🎉
  4. Drafts stay hidden until you publish them.

PDF novels

  1. Upload the PDF in the PDF / Book file section of the novel editor.
  2. Readers read it inside the site with the built-in PDF reader — page by page, with day/sepia/night themes.
  3. Text files (.txt) work too — they are split into chapters automatically.

Authors & reviews

  1. Add author profiles under 👥 Authors — name, photo and bio.
  2. Reader reviews arrive under ⭐ Reviews — approve the good ones; only approved reviews show on the site.

Google Drive novels

  1. Upload the novel text file to Google Drive, share as “Anyone with the link”.
  2. Paste the share link in the novel's External source field — the file ID is extracted automatically.
  3. Get a free Drive API key (Google Cloud Console → enable Drive API → create API key) and put it in js/reader.js as DRIVE_API_KEY.
  4. The reader fetches the text through Google's API and renders it inside your site — visitors never see Drive.

Backups
